# Security

taipoo stores form responses submitted by the public, so we take vulnerabilities seriously.

## Reporting

**Don't open a public issue.** Report it privately through [GitHub's private vulnerability reporting](https://github.com/durgeshityaar/taipoo/security/advisories/new) instead.

Include what's affected, steps to reproduce, and the impact you expect. We'll acknowledge your report within a few days and keep you updated until it's fixed.

## Supported versions

Only the latest `main` gets security fixes.
